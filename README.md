# Галактика — демо Telegram Mini App

Самостоятельная демонстрационная версия на основе ранее созданного мини-приложения. Откройте index.html либо запустите локальный сервер:

```sh
python3 -m http.server 4175 --bind 127.0.0.1
```

Каталог из шести услуг, фильтры, подробные карточки и тестовая запись. Форма не отправляет и не сохраняет данные; бот и сервер не подключены. В Telegram SDK используются только настройка оформления и открытие ссылки контакта. Приложение работает и без SDK.

Источник названия, услуг и контактов: https://t.me/s/galaticadetailing (проверено 10.10.2026). Контакт студии: @GalactiaDetailingMoscow, +7 (968) 382-44-44. Цены — по запросу. Адрес и график не указаны, так как не подтверждены.

Цвета, типографический знак и обложка — концепция демоверсии, не официальный фирменный стиль. Иллюстрация перенесена из исходного демо; это не фотография работ студии.

## Подключение в Telegram

В @BotFather выберите нужного бота: /mybots → Bot Settings → Configure Mini App. Включите Mini App и укажите HTTPS-адрес выше. Для кнопки меню задайте тот же адрес и подпись «Открыть демо» через Menu Button или /setmenubutton.

Канал @GalaticaDetailing и контакт @GalactiaDetailingMoscow не используются как бот приложения. Для Mini App нужен отдельный бот; его подключение выполняется отдельно после выбора пользователем.
